# MinStack

Implement a stack that can also report its smallest value.

```python
class MinStack:
    def push(self, value: int) -> None: ...
    def pop(self) -> int | None: ...
    def top(self) -> int | None: ...
    def get_min(self) -> int | None: ...
    def size(self) -> int: ...
```

- `pop`, `top` and `get_min` return `None` on an empty stack rather than raising.
- **`get_min` must not scan the contents.** Every operation is expected to be O(1).
